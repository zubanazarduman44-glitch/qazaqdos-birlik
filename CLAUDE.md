# Qyzyl til — notes for Claude

Kazakh-learning site «Qyzyl til» (from the proverb «Өнер алды — қызыл тіл»). Live: https://tilim-kz.vercel.app (Vercel auto-deploys every push to `main`; the old qazaqdos-birlik.vercel.app redirects there).

## Working with the owner
- The owner does not code and does not use GitHub. They ask for changes in chat; Claude edits, verifies, commits and pushes to `main` itself.
- Reply in **Kazakh** (the owner sometimes writes Russian or Kazakh in Latin/translit). Keep replies short and concrete.
- Never ask for, print or commit secrets or env values. The owner sets Vercel/Supabase settings themselves. Never put the owner's email in repo files (`supabase/admin.sql` uses the placeholder `YOUR_EMAIL`).
- Don't change landing-page texts (`app/page.js`) unless asked. The owner rejected a restructured home page — the «Basty» home (`app/app/page.js`) keeps its sections and order.
- Before pushing, always run `npm run build` — a broken build means the live site silently stays old.

## Stack
- Next.js 15 App Router, React 19, plain CSS (no Tailwind), no other deps.
- Supabase (auth + REST, SQL in `supabase/`), Google Gemini via `lib/gemini.js` (`callGemini` with model fallback/cooldown and Gemma fallback; `streamGemini` for the Aqyl chat). TTS: `app/api/tts/route.js` (Gemini TTS, `languageCode: kk-KZ`, PCM cleanup) + `lib/speak.js` (client cache, prefetch, stale-audio guard).
- Client state: localStorage `qd_state_v1` via `app/components/Store.js` `useApp()` (`state, lang, explain, award(xp, coins), t`). Keep the state shape backward compatible.
- Global CSS order is set in `app/layout.js` (globals, app, nat, kiiz, lesson, games, travel, aqyl, qyzyl, shell, paper, anim, rtl). Page CSS is imported from each page.

## Rules
- **11 languages** for every new UI label: kk, ru, en, zh, es, de, fr, tr, ar, ko, ja (ar is RTL via `app/rtl.css`). Follow the pattern of the file you touch (`lib/ui/<lang>.js`, or local `*L10n.js`). Kazakh must be natural literary Kazakh. Language is switched only in Profile (and landing/auth before login).
- **Design** (full doc: `claude/design-system.md` in the claude.ai project «qyzyl»): Әдебиет «paper» style via `app/paper.css`; background «Ақ киіз» `#fcfaf6`; palette B — red `#a3242b`/`#741820`, teal `#0b6e7e` (text/buttons) / `#0e8fa3` (fills only), gold `#e8b23a` (fills only, never small text), ink `#1f2430`, cards white; wrong answers wine `#6e1e2e` on `#f3e3e6` dashed (never brand red), correct green `#2f6b4f`. Section accents in `lib/sections.js`.
- Kazakh motifs (тұмар bead, қошқар мүйіз divider, шаңырақ watermark, horn corners, door-arch plinths) are small (≤32px) and sparse. **No ornament strips under headings, no ornament wallpaper** — the owner removed them.
- No emoji as icons (use `Icon.js` / `ShellGlyph.js` / SVG). Touch targets ≥44px. 390px phones: no horizontal scroll, nothing under the bottom nav. Animate transform/opacity only; respect `prefers-reduced-motion`.
- Performance matters (goal: open in 2–3 s): lazy-load heavy art/data, load only the active language where possible.
- Literature episodes are adapted retellings, labelled «Бейімделген үзінді» — don't paste verbatim copyrighted text.
- Commit trailers as the session requires; push with `git push origin HEAD:main`.
